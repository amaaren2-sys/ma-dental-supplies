# MA Dental Supplies — النسخة الاحترافية

متجر Full-Stack جاهز كبنية أولية قابلة للتطوير، مبني بـ Node.js + Express + HTML/CSS/JavaScript.

## المزايا
- متجر ومنتجات
- صفحة تفاصيل لكل منتج
- بحث وتصنيف
- سلة مشتريات محفوظة في المتصفح
- Checkout وإنشاء طلب
- إرسال تفاصيل الطلب إلى WhatsApp
- حفظ الطلبات في `data/orders.json`
- لوحة تحكم Admin
- إضافة/تعديل/حذف المنتجات
- تغيير حالة الطلب
- إحصائيات بسيطة
- تصميم RTL ومتجاوب للموبايل

## التشغيل

1. ثبّت Node.js.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:
   ```bash
   npm install
   ```
4. انسخ `.env.example` إلى `.env` وعدّل:
   - `ADMIN_PASSWORD`
   - `WHATSAPP_NUMBER`
5. شغّل:
   ```bash
   npm start
   ```
6. افتح:
   `http://localhost:3000`

## لوحة التحكم

الرابط:
`http://localhost:3000/admin.html`

كلمة المرور الافتراضية من `.env`.

> النسخة الحالية تستخدم ملفات JSON كقاعدة بيانات بسيطة حتى تعمل بسهولة بدون MySQL/MongoDB. عند الإطلاق الحقيقي يمكن نقلها إلى PostgreSQL أو MySQL، وإضافة حسابات Admin حقيقية وصلاحيات.

## بيانات المتجر

عدّل المنتجات التجريبية من لوحة التحكم، أو ملف:
`data/products.json`

الطلبات تحفظ في:
`data/orders.json`

## قبل الإطلاق الحقيقي
- ضع رقم WhatsApp الحقيقي.
- ضع صور المنتجات الحقيقية.
- ضع بيانات الشركة وسياسات الخصوصية والاسترجاع.
- اربط نطاق HTTPS.
- استخدم قاعدة بيانات حقيقية عند زيادة الطلبات.
- أضف نظام دخول Admin آمنًا ومفاتيح جلسات في بيئة الإنتاج.
- لا تخزن بيانات دفع حساسة في هذا المشروع.
